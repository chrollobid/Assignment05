
1️⃣ What is the difference between var, let, and const?
answer: the main difference is 'var' is function-scoped and 'let' , 'const' are block-scoped and can't be redeclared. In 'let' you can change the value but in 'const' it is constant.



2️⃣ What is the spread operator (...)?
answer: It is a modern js tool that allows to iterable to be 'expanded' into individual elements.




3️⃣ What is the difference between map(), filter(), and forEach()?
answer: forEach(): it executes a function for each element to perform an action (like logging or updating the DOM) but returns undefined.

map(): it creates a new array by transforming every element of the original array.

filter(): it creates a new array containing only the elements that meet a specific condition.




4️⃣ What is an arrow function?
answer: it is a shorter way to write function in javascript and it is introduced in ES6



5️⃣ What are template literals?
answer: template literals are a modern way to create strings in JS using backticks(`) instead of quotes.
